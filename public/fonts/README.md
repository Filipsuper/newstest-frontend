# Geist for social images

Static 400 and 600 TrueType weights of the same open-source Geist family used
by the public UI. ImageResponse/Satori needs TrueType rather than the UI's
variable WOFF2. These assets are bundled; rendering makes no font-network call.

Retrieved 7 September 2026 from Google Fonts' Geist stylesheet:
https://fonts.googleapis.com/css2?family=Geist:wght@400;600
